{# Origin folder navigation for the admin image / video feeds. The gallery on disk is ///, so "origin" is a real folder, not a tag. The admin pages used to show every origin's output in one undifferentiated stream; this partial turns that stream into a two-level browse: * the page opens INSIDE the session origin's own folder — the only folder an admin ever generates into; * stepping up shows one card per origin folder (cover, count, size, last activity), and opening one browses that origin's media. Navigation is frozen while a generation is in flight: the live placeholder tiles live in this same grid and resolve into the finished media in place, so swapping the feed underneath them would strand them. The composer also snaps back to the admin's own folder when Generate is pressed, because that is where the result will land. API: LMGalleryScope.create(opts) -> controller opts.bar element the breadcrumb strip opts.grid element the feed grid (folder cards go here) opts.selfOrigin string the session origin — the opening folder opts.kind "image"|"video" opts.originsUrl string /ui/images/gallery/origins opts.authHeaders () => headers | null opts.onChange (origin|null) => void reload the feed for this scope opts.onError (message) => void opts.spanCard (card) => void the page's masonry sizer controller.current() -> origin name, or null at the parent level controller.isRoot() -> true at the parent level controller.goTo(name|null) -> Promise, resolved once onChange has controller.setBusy(bool) disable navigation during a generation controller.renderFolders() fetch + draw the folder cards into the grid controller.render() redraw the breadcrumb only #}
