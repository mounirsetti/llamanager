Claude Desktop stdio

Claude Desktop launches a child process rather than dialling a URL, so it uses the mcp-stdio verb, which proxies this daemon. On this machine the key is optional — llamanager falls back to the loopback-only control key in its data directory. 

{
  "mcpServers": {
    "llamanager": {
      "command": "llamanager",
      "args": ["mcp-stdio"],
      "env": { "LLAMANAGER_ADMIN_KEY": "{{ key }}" }
    }
  }
}
