{# Gallery tile media loader — shared by images.html, videos.html and their bearer-authenticated public twins. What it fixes: the grid used to fetch every full-size PNG / whole MP4 the moment the listing arrived (60 at once, ~1–5 MB each), draw nothing until each finished, and swallow every failure — a dropped request left a blank tile forever. Now a tile: * reserves its aspect ratio from the listing before any byte arrives; * loads the server-side JPEG thumbnail (thumbs.py), not the original; * loads only when it scrolls near the viewport, at most MAX_INFLIGHT at a time, newest-visible first; * shows a visible error state with a Retry button when a load fails. Originals are still used for the lightbox and for hover-preview of clips. API: LMGalleryMedia.attach(card, item, opts) opts.authHeaders () => headers bearer pages: media fetched as blobs; null cookie pages: straight. opts.isVideo boolean opts.onSize (w, h) => void called with intrinsic dimensions. #}
