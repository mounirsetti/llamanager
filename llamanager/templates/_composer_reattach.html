{# Keeps a running generation visible across a page close. A generation is a queued job on the server, not a property of the browser connection that started it. Close the tab during a four-minute clip and the GPU keeps working, but the page came back looking idle — no progress, no indication anything was happening, and the result appearing in the gallery minutes later with no explanation. The admin images page grew its own reattach for exactly this. The other three (admin video, public image, public video) had none, so this partial gives them a smaller version of the same idea: on load, ask the server what it is doing; if something is running, show it and poll until it finishes, then refresh so the result appears. A page that already reattaches on its own sets window.LM_HAS_REATTACH before including this, and it stands down. Optional hook: window.LM_ON_JOB_DONE() is called when the watched job ends. Without one the page reloads, which is enough to surface the result in every gallery here. #}
