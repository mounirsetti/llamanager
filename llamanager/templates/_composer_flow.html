{# Guided generation flow: model → mode → the settings that follow. Generation is a process — pick the model, then whether this is a new image or an edit of an existing one — but the composer presented model, profile and eleven settings as one flat surface, and whether a reference image did anything depended on which profile happened to be selected. The modes come from data the pages already load: every profile carries ``caps`` (engines.profile_capabilities), and profiles whose caps name a ``mode`` group into chips. Krea 2: "New image" / "Edit an image" — the umbrella the user asked for needs no model merging, editing already IS Krea 2 with an edit LoRA selected. MiniMax-H3: "Animate a photo" (FL2VA, exactly one opening frame) / "From references" (REF2VA, 1–9). Models with one mode show no chips at all. Attaching a reference while in a no-reference mode switches to the reference mode rather than ignoring the file: stock Krea 2 has no image-conditioning path, so a reference IMPLIES the edit path. A notice says so, and removing the last reference offers the way back. Self-contained in the _composer_warm.html mold: boots on DOMContentLoaded (the page's inline LM_IMAGES_CFG script runs first), observes the DOM the four pages already build, edits none of their copy-pasted JS. #}
